# تشغيل اللغات دون إنترنت

يجب تثبيت بيئات التشغيل وتجهيزها مسبقاً؛ التطبيق لا ينزّلها تلقائياً.

- **Python:** ثبّت Python 3 وتأكد أن `python` أو `py` يعمل من PowerShell.
- **Java:** ثبّت JDK كاملاً؛ يلزم `javac` للترجمة و`java` للتشغيل. استخدم قالب `public class Main`.
- **C#:** ثبّت .NET SDK. إنشاء مشروع جديد قد يتطلب استعادة حزم؛ جهّز SDK والحزم مسبقاً للبيئات المعزولة.
- **JavaScript:** ثبّت Node.js وتأكد من الأمر `node`.
- **HTML/CSS:** لغتا توصيف وتنسيق، ولا تعملان كبرنامج نصي منفصل. لا تتوفر معاينة مدمجة في هذه النسخة.
- **SQL:** صفحة SQL تستخدم SQLite المحلية، وتسمح باستعلامات قراءة فقط تبدأ بـ SELECT أو PRAGMA.

لا تشغّل أكواداً مجهولة. هذه بيئة تعليمية وليست بيئة تشغيل معزولة.
