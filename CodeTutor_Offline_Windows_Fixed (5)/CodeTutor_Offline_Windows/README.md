# CodeTutor Offline — منصة تعليم البرمجة لويندوز

منصة Flutter/Dart بواجهة عربية RTL وقاعدة SQLite محلية. صُممت لتعمل دون اتصال بعد تنزيل الحزم وتجهيز بيئات تشغيل اللغات على الجهاز.

## الوظائف الموجودة في المشروع
- تسجيل دخول محلي بالاسم واختيار الدور (طالب/مدرس/مدير). **هذا ليس نظام مصادقة آمنًا**؛ لا تستخدمه لحماية بيانات حساسة.
- سبعة مسارات: Python وJava وC# وJavaScript وHTML وCSS وSQL. قاعدة البيانات تنشئ 60 سجل درس لكل مسار عند أول تشغيل (420 سجلًا).
- فتح الدروس وعرض الأمثلة، إرسال المثال إلى المحرر، وحفظ إكمال الدروس والنتائج محليًا.
- محرر وتشغيل محلي لـ Python/JavaScript/Java/C# عند توفر أدوات اللغة في PATH. تشغيل الكود ينفذ بصلاحيات مستخدم Windows ولا يوجد عزل أمني؛ لا تشغّل كودًا مجهولًا.
- مختبر SQL يسمح بقراءة البيانات عبر SELECT/PRAGMA.
- صفحة إدارة المحتوى: المعلم والمدير يمكنهما تحرير الدروس والأمثلة وإضافة دروس؛ المدير يمكنه تعديل بيانات المسار.
- صفحة نتائج وتقدم، وإعدادات توضح مسار بيانات التطبيق.

## مهم بشأن المحتوى
سجلات الدروس الـ420 هي **هيكل تعليمي أولي** وليست 420 درسًا مكتملًا ومراجعًا. لكل درس عنوان ومقدمة مختصرة ومثال وتمرين عام. استخدم صفحة الإدارة لتطوير المحتوى، وراجع الأمثلة قبل التدريس. HTML/CSS لا تحتويان على معاينة مدمجة في هذه النسخة.

## المتطلبات
1. Windows 10/11 64-bit.
2. Flutter SDK (المشروع اختُبر بنيويًا فقط في بيئة الإنشاء؛ نفّذ التحليل والبناء على جهازك).
3. Visual Studio 2022 مع workload **Desktop development with C++** وWindows SDK. Android Studio وحده لا يبني تطبيق Windows.
4. اتصال أولي لتنزيل الحزم (`flutter pub get`) ما لم تكن متوفرة في ذاكرة الحزم. بعد البناء، قاعدة البيانات والتعلّم يعملان محليًا.

## تشغيل المشروع
افتح PowerShell داخل مجلد المشروع:

```powershell
flutter doctor
flutter config --enable-windows-desktop
flutter create --platforms=windows .
flutter pub get
flutter analyze
flutter run -d windows
```

إذا كانت ملفات `windows` موجودة بالفعل، راجع التغييرات التي سيجريها `flutter create` قبل الموافقة. أصلح أخطاء `flutter analyze` قبل البناء.

## بناء نسخة Release
```powershell
flutter build windows --release
```
المخرجات عادةً في `build\windows\x64\runner\Release\`. انسخ مجلد Release كاملًا، لا تنسخ ملف EXE وحده. اختبر على جهاز آخر قبل التوزيع.

## بيئات تشغيل اللغات (اختيارية)
- Python: `python --version` أو `py --version`
- Java: `javac -version` و`java -version`
- JavaScript: `node --version`
- C#: `dotnet --info`؛ قد يحتاج أول بناء إلى حزم محلية.
- SQL: SQLite مدمج في التطبيق.

## النسخ الاحتياطي
قاعدة البيانات `code_tutor.db` موجودة في مجلد بيانات التطبيق الذي تعرضه صفحة الإعدادات. أغلق التطبيق قبل نسخ الملف. لا تحذف الملف إذا أردت الاحتفاظ بالتقدم والتعديلات.

## حدود النسخة الحالية
- الأدوار اختيار محلي للتنقل وليست مصادقة حقيقية ولا تمنع الوصول الأمني إلى قاعدة البيانات.
- لا يوجد مزامنة بين أجهزة أو نظام حسابات متعدد المستخدمين آمن؛ البيانات على جهاز واحد.
- لا يوجد sandbox لتشغيل الأكواد، ولا معاينة HTML/CSS مدمجة، ولا نظام اختبارات متكامل بمصحح آلي في كل درس.
- يلزم تشغيل `flutter analyze` و`flutter run -d windows` على جهاز Windows المزود بأدوات البناء للتأكد من البناء الفعلي.
